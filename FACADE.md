# QueueFlow Go facade

The facade documentation has moved into [README.md](./README.md), which is the single entry point
for this package: install, quick start, the `QueueFlow` client, the `WorkflowBuilder`, the
generated client, authentication, the worker protocol, error handling, and the conformance tests.

`facade.go` is injected at generation time from the queueflow-core template
(`sdk-templates/go/facade.mustache`); edit the template, not the file.
